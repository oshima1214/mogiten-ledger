# mogiten-ledger 設計仕様

模擬店を出すグループが、準備で**購入した**物品のレシートを店ごとに記録して集計し、表形式のPDFで出力するアプリ。

## 利用環境
- 主にスマホのブラウザ。PCのブラウザでも使えること（レスポンシブ）。
- データは端末内（ブラウザの localStorage）にのみ保存。サーバーは使わない。

## 画面構成

### 1. ホーム画面
- 左上：グループ名（未登録なら「mogiten-ledger」）。
- 右上：「PDF出力」ボタン。その下に「集計」ボタン（2. 集計画面へ）。
- 中央：記録したレシート（店ごと）を横長のカードで縦に並べ、縦スクロール。
  - カードに出すもの：店名、「外税」「内税」の表示、商品名（最大3つ。4つ以上なら「…ほか N 点」）、合計金額、「編集」ボタン。
  - 「編集」は 3. レシート入力画面を、その店の内容が入った状態で開く。
- 画面下中央：主ボタン「＋ レシートを記録」（3. へ）。
- レシートが0件なら中央に案内文を出す。

### 2. 集計画面
模擬店終了後に入力する。すべて任意入力。
- 受け取った金券の枚数（枚）
- 予算（円）
- 総費用（円）。参考としてレシート合計を表示し、ボタン1つで入力欄に写せる。
- 残金（円）。参考として「予算 − 総費用」を表示し、ボタン1つで写せる。
- メニューごとの売上個数：メニュー名と個数の行を自由に追加・削除できる（グループごとに数が違う）。
- 入力は自動保存。

### 3. レシート入力画面
- **グループ情報**：レシートが1件も無く、グループ情報も未登録のときだけ最初に出す。グループ名と代表者名を入力（両方必須）。
- **ステップ1 店**：店名（必須）と、レシートが「外税」か「内税」か（初期は未選択、必須）を同じ画面で選ぶ。「次へ」で進む。
- **ステップ2 購入品**：
  - 購入品は折りたたみ式の欄で1つずつ入力する。1つ目は開いた状態。「購入品を追加する」で欄が増え、新しい欄が開く。
  - 各欄：商品名（必須）、金額（円、1以上の整数、必須）、外税の店のみ税率 8% / 10%（初期は未選択、必須）。
  - 内税の店では税率も税額も入力させない。
  - 欄を閉じても、見出しに商品名・税率・金額が見える。欄ごとに削除できる。
  - 下部に「入力を終える」ボタン。入力に誤りがある欄は開いてエラーを出し、保存しない。
  - ステップ1へ戻れる（入力内容は保持）。
- **編集時**：同じ画面配置で、既存の内容が入った状態から始まる。このレシートを削除するボタンもある。

## 計算ルール
- 外税の税額 = floor(税率ごとの小計 × 税率)。端数は切り捨て。レシートごと・税率ごとに1回だけ計算。
- 外税のレシートの合計 = 8%小計 + 10%小計 + 8%税額 + 10%税額。
- 内税のレシートの合計 = 金額の合計（入力した金額は税込）。税額の行は出さない。
- 税額が0円の税率の行は画面にもPDFにも出さない。
- 総合計 = 全レシートの合計の和。

## PDF
- 上部：タイトル「模擬店 購入記録」、グループ名、代表者名、出力日。
- 表：| 店名 / 商品名 | 税率 | 金額 |
  - レシートごとに見出し行「店名（外税）」「店名（内税）」、商品の行（内税は税率欄が空）、外税のみ「消費税 8%」「消費税 10%」（0円は出さない）、「店の合計」。
  - 最後に「総合計」。
- 集計画面で何か入力されていれば、その下に「集計」の表（金券枚数・予算・総費用・残金）と「メニュー別売上個数」の表。入力のない項目の行は出さない。
- 日本語フォントを埋め込む。
