# mogiten-ledger 設計仕様

模擬店で**購入した**商品を、店ごとに記録して集計し、表形式のPDFで出力するアプリ。

## 利用環境
- 主にスマホのブラウザ。PCのブラウザでも使えること（レスポンシブ）。
- データは端末内（ブラウザの localStorage）にのみ保存。サーバーは使わない。

## 機能要件
1. **店の登録**：店名を入力して店を追加する。購入記録は店ごとにまとめて表示する。
2. **レシートの税表示**：店ごとに「外税」か「内税」かを選ぶ。
3. **商品の入力**：商品1つ単位で、商品名と金額（円、整数）を入力する。
   - 税率（8% / 10%）は**初期状態では未選択**。8%か10%を選ばないと商品を登録できない。
4. **外税の税額表示**：外税の店では、8%対象商品の小計から8%の税額を、10%対象商品の小計から10%の税額をそれぞれ計算して表示する。
   - 税額が0円の税率の行は表示しない。
5. **PDF出力**：最終的な出力はPDF。見た目は表形式。

## 計算ルール（このアプリで決めたもの）
- 外税の税額 = floor(税率ごとの小計 × 税率)。端数は**切り捨て**。レシート1枚（店）ごと・税率ごとに1回だけ計算する。
- 外税の店の合計 = 8%小計 + 10%小計 + 8%税額 + 10%税額。
- 内税の店の合計 = 商品金額の合計（入力した金額は税込）。内税の店には税額の行を出さない。
- 総合計 = 全店舗の合計の和。

## PDFの表の構成
| 店名 / 商品名 | 税率 | 金額 |
- 店ごとに見出し行「店名（外税）」または「店名（内税）」を置く
- 商品の行
- 外税の店のみ「消費税 8%」「消費税 10%」の行（0円の行は出さない）
- 「店の合計」の行
- 最後に「総合計」の行
- 日本語が正しく表示されること（日本語フォントを埋め込む）
